# React Resume Platform

Personal resume and portfolio website built with React and Vite.

This project is also being developed as a hands-on cloud engineering project. The application will be containerized and deployed to AWS, with infrastructure managed through Terraform, automated deployments through GitHub Actions, and monitoring through Amazon CloudWatch.

Troubleshooting documentation https://www.linkedin.com/pulse/deployed-react-app-aws-ecs-fargate-vpc-terraform-ci-github-melvin-afbic
